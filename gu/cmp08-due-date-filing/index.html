CMP-08 કેવી રીતે ફાઇલ કરવું

CMP-08 ટૂંકું સ્ટેટમેન્ટ છે: તમે ત્રિમાસિકનું ટર્નઓવર જાહેર કરો છો અને ટેક્સ રોકડે ભરો છો. દરેક બિલની વિગત પૂછાતી નથી.

છેલ્લી તારીખો

ત્રિમાસિકCMP-08 છેલ્લી તારીખ
એપ્રિલ–જૂન18 જુલાઈ
જુલાઈ–સપ્ટેમ્બર18 ઑક્ટોબર
ઑક્ટોબર–ડિસેમ્બર18 જાન્યુઆરી
જાન્યુઆરી–માર્ચ18 એપ્રિલ

વાર્ષિક રિટર્ન GSTR-4 નાણાકીય વર્ષ પછીની 30 જૂન સુધી ભરવાનું હોય છે (FY 2024-25 થી, જાહેરનામું 12/2024-Central Tax; અગાઉ 30 એપ્રિલ હતી). તારીખો જાહેરનામાથી વધારી શકાય છે; તમારું Returns Dashboard તપાસો.

GST પોર્ટલ પરનાં પગલાં

  1. હોમ પેજ પર વર્કિંગ બનાવો અને CGST અને SGST ના કુલ આંકડા નોંધો.
  2. ઇલેક્ટ્રોનિક કેશ લેજરમાં પૂરતી રકમ ન હોય તો ચલણ બનાવો: Services › Payments › Create Challan, અને નેટ બેંકિંગ, UPI કે બેંકમાં ભરો.
  3. Services › Returns › Returns Dashboard પર જાઓ, વર્ષ અને ત્રિમાસિક પસંદ કરો, અને GST CMP-08 ટાઇલમાં Prepare Online પસંદ કરો.
  4. આઉટવર્ડ ટર્નઓવર અને ટેક્સ, રિવર્સ ચાર્જ ટેક્સ અને વ્યાજ હોય તો તે લખો.
  5. પ્રીવ્યૂ તપાસો, પછી DSC કે EVC (OTP) થી File કરો.

નિલ CMP-08

ત્રિમાસિકમાં વેચાણ અને રિવર્સ ચાર્જ ખરીદી ન હોય તો નિલ CMP-08 ફાઇલ કરો. તે નોંધાયેલા મોબાઇલ નંબર પરથી SMS દ્વારા પણ ફાઇલ થઈ શકે છે; SMS નું ફૉર્મેટ પોર્ટલ Help માં સમજાવે છે.

વ્યાજ અને લેટ ફી

  • 18 તારીખ પછી ભરેલા ટેક્સ પર મોડા પડેલા દિવસો માટે વર્ષે 18% વ્યાજ લાગે છે (કલમ 50). તે વર્કિંગના વ્યાજ બોક્સમાં લખો.
  • મોડા GSTR-4 પર દરરોજ લેટ ફી લાગે છે, ટોચમર્યાદા સાથે; પોર્ટલ બતાવે તે રકમ તપાસો.
આ ત્રિમાસિકનું CMP-08 હમણાં જ કાઢો.મેકર ખોલો
