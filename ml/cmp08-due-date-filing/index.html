CMP-08 എങ്ങനെ ഫയൽ ചെയ്യാം

CMP-08 ഒരു ചെറിയ സ്റ്റേറ്റ്മെന്റ് ആണ്: നിങ്ങൾ പാദത്തിലെ ടേൺഓവർ പ്രഖ്യാപിച്ച് ടാക്സ് ക്യാഷായി അടയ്ക്കുന്നു. ഓരോ ബില്ലിന്റെയും വിവരങ്ങൾ ചോദിക്കില്ല.

അവസാന തീയതികൾ

പാദംCMP-08 അവസാന തീയതി
ഏപ്രിൽ–ജൂൺ18 ജൂലൈ
ജൂലൈ–സെപ്റ്റംബർ18 ഒക്ടോബർ
ഒക്ടോബർ–ഡിസംബർ18 ജനുവരി
ജനുവരി–മാർച്ച്18 ഏപ്രിൽ

വാർഷിക റിട്ടേൺ GSTR-4 സാമ്പത്തിക വർഷത്തിന് ശേഷമുള്ള 30 ജൂണിനകം (FY 2024-25 മുതൽ, വിജ്ഞാപനം 12/2024-സെൻട്രൽ ടാക്സ്; മുമ്പ് 30 ഏപ്രിൽ ആയിരുന്നു). തീയതികൾ വിജ്ഞാപനം വഴി നീട്ടാം; നിങ്ങളുടെ Returns Dashboard നോക്കുക.

GST പോർട്ടലിലെ ഘട്ടങ്ങൾ

  1. ഹോം പേജിൽ വർക്കിംഗ് ഉണ്ടാക്കി CGST, SGST ആകെ തുകകൾ കുറിച്ചുവയ്ക്കുക.
  2. ഇലക്ട്രോണിക് ക്യാഷ് ലെഡ്ജറിൽ മതിയായ തുക ഇല്ലെങ്കിൽ ചലാൻ ഉണ്ടാക്കുക: Services › Payments › Create Challan, നെറ്റ് ബാങ്കിംഗ്, UPI വഴിയോ ബാങ്കിൽ ചെന്നോ അടയ്ക്കുക.
  3. Services › Returns › Returns Dashboard ലേക്ക് പോയി വർഷവും പാദവും തിരഞ്ഞെടുത്ത്, GST CMP-08 ടൈലിൽ Prepare Online തിരഞ്ഞെടുക്കുക.
  4. പുറത്തേക്കുള്ള വിതരണത്തിന്റെ ടേൺഓവറും ടാക്സും, റിവേഴ്സ് ചാർജ് ടാക്സും, പലിശയും (ഉണ്ടെങ്കിൽ) ടൈപ്പ് ചെയ്യുക.
  5. പ്രിവ്യൂ പരിശോധിച്ച ശേഷം DSC അല്ലെങ്കിൽ EVC (OTP) ഉപയോഗിച്ച് File ചെയ്യുക.

Nil CMP-08

പാദത്തിൽ വിൽപനയും റിവേഴ്സ് ചാർജ് വാങ്ങലുകളും ഇല്ലെങ്കിൽ Nil CMP-08 ഫയൽ ചെയ്യുക. രജിസ്റ്റർ ചെയ്ത മൊബൈൽ നമ്പറിൽ നിന്ന് SMS വഴിയും ഇത് ഫയൽ ചെയ്യാം; SMS ഫോർമാറ്റ് പോർട്ടൽ Help ന് കീഴിൽ വിശദീകരിക്കുന്നു.

പലിശയും ലേറ്റ് ഫീയും

  • 18ന് ശേഷം അടച്ച ടാക്സിന് വൈകിയ ദിവസങ്ങൾക്ക് വർഷം 18% പലിശ (സെക്ഷൻ 50). അത് വർക്കിംഗിലെ പലിശ ബോക്സിൽ ടൈപ്പ് ചെയ്യുക.
  • വൈകിയ GSTR-4 ന് ദിവസത്തിനനുസരിച്ച് ലേറ്റ് ഫീ, പരിധിയോടെ; പോർട്ടൽ കാണിക്കുന്ന തുക നോക്കുക.
ഈ പാദത്തിലെ CMP-08 ഇപ്പോൾ തന്നെ കണക്കാക്കുക.മേക്കർ തുറക്കുക
