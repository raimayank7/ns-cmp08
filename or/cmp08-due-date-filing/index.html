CMP-08 କିପରି ଫାଇଲ୍ କରିବେ

CMP-08 ଏକ ଛୋଟ ଷ୍ଟେଟମେଣ୍ଟ: ଆପଣ କ୍ୱାର୍ଟରର ଟର୍ନଓଭର୍ ଘୋଷଣା କରନ୍ତି ଓ ଟ୍ୟାକ୍ସ କ୍ୟାସ୍‌ରେ ଶୁଝନ୍ତି। ପ୍ରତ୍ୟେକ ବିଲ୍‌ର ବିବରଣୀ ମାଗାଯାଏ ନାହିଁ।

ଶେଷ ତାରିଖ

କ୍ୱାର୍ଟରCMP-08 ଶେଷ ତାରିଖ
ଏପ୍ରିଲ୍–ଜୁନ୍18 ଜୁଲାଇ
ଜୁଲାଇ–ସେପ୍ଟେମ୍ବର18 ଅକ୍ଟୋବର
ଅକ୍ଟୋବର–ଡିସେମ୍ବର18 ଜାନୁଆରୀ
ଜାନୁଆରୀ–ମାର୍ଚ୍ଚ18 ଏପ୍ରିଲ୍

ବାର୍ଷିକ ରିଟର୍ଣ୍ଣ GSTR-4 ଆର୍ଥିକ ବର୍ଷ ପରର 30 ଜୁନ୍ ଭିତରେ (FY 2024-25 ରୁ, Notification 12/2024-Central Tax; ଆଗରୁ 30 ଏପ୍ରିଲ୍ ଥିଲା)। ବିଜ୍ଞପ୍ତି ଦ୍ୱାରା ତାରିଖ ବଢ଼ାଯାଇପାରେ; ଆପଣଙ୍କ Returns Dashboard ଦେଖନ୍ତୁ।

GST ପୋର୍ଟାଲରେ ପାହାଚଗୁଡ଼ିକ

  1. ହୋମ୍ ପେଜ୍ ରେ ହିସାବ କରନ୍ତୁ ଓ CGST ଓ SGST ମୋଟ ଲେଖିନିଅନ୍ତୁ।
  2. ଇଲେକ୍ଟ୍ରୋନିକ୍ କ୍ୟାସ୍ ଲେଜର୍‌ରେ ଯଥେଷ୍ଟ ନଥିଲେ, ଚାଲାନ୍ ବନାନ୍ତୁ: Services › Payments › Create Challan, ଆଉ ନେଟ୍ ବ୍ୟାଙ୍କିଂ, UPI ବା ବ୍ୟାଙ୍କରେ ଦିଅନ୍ତୁ।
  3. Services › Returns › Returns Dashboard କୁ ଯାଆନ୍ତୁ, ବର୍ଷ ଓ କ୍ୱାର୍ଟର ବାଛନ୍ତୁ, ଆଉ GST CMP-08 ଟାଇଲ୍‌ରେ Prepare Online ବାଛନ୍ତୁ।
  4. ଆଉଟୱାର୍ଡ ଟର୍ନଓଭର୍ ଓ ଟ୍ୟାକ୍ସ, ରିଭର୍ସ ଚାର୍ଜ ଟ୍ୟାକ୍ସ ଓ ସୁଧ, ଯଦି ଅଛି, ଟାଇପ୍ କରନ୍ତୁ।
  5. ପ୍ରିଭ୍ୟୁ ଦେଖନ୍ତୁ, ତା’ପରେ DSC ବା EVC (OTP) ସହିତ File କରନ୍ତୁ।

ନିଲ୍ CMP-08

କ୍ୱାର୍ଟରରେ କୌଣସି ବିକ୍ରି ଓ ରିଭର୍ସ ଚାର୍ଜ କିଣା ନଥିଲେ, ନିଲ୍ CMP-08 ଫାଇଲ୍ କରନ୍ତୁ। ଏହାକୁ ରେଜିଷ୍ଟର୍ଡ୍ ମୋବାଇଲ୍ ନମ୍ବରରୁ SMS ଦ୍ୱାରା ମଧ୍ୟ ଫାଇଲ୍ କରିହେବ; SMS ଫର୍ମାଟ୍ ପୋର୍ଟାଲ୍ Help ତଳେ ବୁଝାଏ।

ସୁଧ ଓ ଲେଟ୍ ଫି

  • 18 ତାରିଖ ପରେ ଦିଆଯାଇଥିବା ଟ୍ୟାକ୍ସରେ ଡେରିର ଦିନ ଅନୁସାରେ ବର୍ଷକୁ 18% ସୁଧ ଲାଗେ (ଧାରା 50)। ଏହାକୁ ହିସାବର ସୁଧ ବକ୍ସରେ ଟାଇପ୍ କରନ୍ତୁ।
  • ଡେରିରେ GSTR-4 ପାଇଁ ପ୍ରତି ଦିନ ଲେଟ୍ ଫି ଲାଗେ, ସୀମିତ; ପୋର୍ଟାଲ୍ ଦେଖାଉଥିବା ରାଶି ଦେଖନ୍ତୁ।
ଏହି କ୍ୱାର୍ଟରର CMP-08 ହିସାବ ଏବେ କରନ୍ତୁ।ମେକର୍ ଖୋଲନ୍ତୁ
